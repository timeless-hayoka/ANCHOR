Your first local run

Start with evidence you can inspect.

Run four labeled SARIF signal-processing cases on your own machine. This checks ingestion, deduplication, filtering, and classification. It does not reproduce an exploit or test a live target.

Python 3.11+No wallet or RPCNo API key

1 · Prepare a local environment

Use Git and Python 3.11 or newer in a Linux, macOS, or Windows WSL terminal. Internet access is needed to clone and install dependencies; the corpus uses bundled inputs. Run from a fresh checkout.

git clone https://github.com/timeless-hayoka/ANCHOR.git
cd ANCHOR
python3 --version
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt

Check that the Python version is at least 3.11. The commands call the virtual environment directly; activation is optional.

2 · Run the bundled corpus

.venv/bin/python anchor_cli.py benchmark sarif known-findings
.venv/bin/python scripts/verify_sarif_benchmark.py

The runner prints the run ID and report path. Expected verifier output for the current corpus:

PASS: 4 labeled cases; no FP/FN; positive and negative controls verified

Expected: 3 true positives, 1 true negative, no false positives or false negatives. These are signal-visibility checks on a small corpus. They do not establish exploitable vulnerabilities or general detection accuracy. If verification fails, preserve the failed outputs and inspect the error.

3 · Inspect what happened

Open the exact timestamped directory printed by the runner under benchmarks/sarif-known-findings/runs/.

ArtifactWhat it tells you
REPORT.mdPer-case outcomes and limitations
benchmark.jsonExpected versus actual visibility, classifications, and summary counts
metrics.jsonCounts and source commit

The runner also updates the local benchmark summary and appends a development entry to the manifest. Generated run directories are ignored by Git. A successful local run is not automatically a published result.

4 · Choose the next step

The install and corpus commands were verified in a fresh virtual environment on November 3, 2026: all four labeled cases passed. That run was a new development check, not a recovery of historical evidence.
